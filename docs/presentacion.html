1. Planteamiento del Problema

Situacion Actual en Pymes

Procesos manuales de gestion humana: contratacion, novedades, vacaciones y liquidacion de nomina con hojas de calculo dispersas.

  • Errores de liquidacion con impacto economico directo en los pagos a empleados
  • Sin trazabilidad ni control de versiones en los datos de nomina
  • Reprocesos administrativos y demoras en atencion de solicitudes
  • Riesgo normativo: incumplimiento de la Ley 1581/2012 en tratamiento de datos personales
  • Sin canal de autoconsulta para los empleados

5. DevOps: Pipeline CI/CD e IaC

Pipeline de Integracion y Despliegue Continuo (GitHub Actions)

Lintruff (PEP 8)
Securitybandit + pip-audit
Testpytest + coverage
BuildDocker image
DeploySSH → Linode VPS

Cada push a main ejecuta el pipeline completo. Los PR solo ejecutan lint, security y tests.

Infraestructura como Codigo (Terraform)

  • main.tf: VPS Nanode 1GB + Linode Cloud Firewall (puertos 80, 443, 22 restringido)
  • cloud-init.yaml: Docker, swap 2GB, SSH hardening (ed25519), fail2ban, UFW, unattended-upgrades
  • variables.tf: Token Linode (sensitive), region, SSH key, IPs admin

Entornos reproducibles y auditables: un terraform apply aprovisiona toda la infra desde cero.

Flujo de Despliegue

  1. git push origin main
  2. GitHub Actions ejecuta lint + security + tests
  3. Build de imagen Docker multi-stage
  4. Deploy via SSH al VPS Linode
  5. docker compose up -d --build
  6. Migraciones + collectstatic automaticos

Basado en The DevOps Handbook (Kim et al., 2021) y Continuous Integration (Fowler, 2006).

6. Estrategia de Seguridad y Cumplimiento Normativo

Seguridad en Profundidad (Defense in Depth)

✓
Capa de red: Linode Cloud Firewall (puertos 80/443) + UFW + fail2ban. SSH solo con llaves ed25519, root login deshabilitado.
✓
Cifrado en transito: TLS 1.2+ con certificados Let's Encrypt (renovacion automatica via Certbot).
✓
Cifrado en reposo: pgcrypto/AES-256 para campos sensibles de nomina (salarios, documentos).
✓
Autenticacion: Contraseñas con Argon2 (OWASP best practice). Validacion minima 10 caracteres.
✓
Autorizacion: Control de acceso por roles (administrador, gestion humana, empleado) con principio de minimo privilegio.
✓
Auditoria: Middleware que registra todas las operaciones de escritura (usuario, IP, timestamp, accion).
✓
Hardening SO: CIS Benchmark Ubuntu, parches automaticos (unattended-upgrades).
✓
Headers HTTP: HSTS, X-Frame-Options DENY, X-Content-Type-Options, Referrer-Policy.

Backups y Recuperacion

Linode Backups ($2/mes): copias automaticas diarias, semanales y por demanda. RPO < 24h. Ruta de escalamiento: resize a Linode 2GB ($12/mes) sin reinstalacion.

Tokens y Secretos

API tokens con alcance minimo y expiracion. Secretos en GitHub Secrets (nunca en codigo). Variables de entorno via .env (excluido de Git).
